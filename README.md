# 📚 PMP Study Guides — Streamlit Edition

A mobile-first PMP exam preparation app built with Streamlit.

## 🚀 Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```

The app will open at `http://localhost:8501`

## 📱 Features

- **📖 Study Guides** — All 10 Knowledge Areas with ITTOs, exam traps, agile notes
- **❓ Question Bank** — 15+ practice questions with filters
- **📝 Quiz Mode** — 10-question random quizzes
- **🗂️ Flashcards** — 50 cards (terms, formulas, ITTOs, agile)
- **🏆 Mock Exams** — 3 full exams with scoring
- **📊 Progress Tracking** — Persistent across sessions

## 🌐 Deploy to Streamlit Cloud

1. Push to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your repo
4. Deploy!
